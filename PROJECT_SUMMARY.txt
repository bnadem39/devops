    → File → Open → Sélectionner le dossier "hotelG"

2️⃣  Configurer JDK 21
    → File → Project Structure → Project
    → SDK : Sélectionner ou télécharger JDK 21 (Temurin)
    → Language level : 21

    → Clic droit sur pom.xml → Maven → Reload Project
    → Attendre le téléchargement des dépendances

    → Ouvrir src/main/java/com/hotel/main/MainApp.java
    → Clic droit sur la classe MainApp
    → Run 'MainApp.main()'
